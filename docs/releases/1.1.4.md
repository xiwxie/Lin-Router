# LinRouter 1.1.4 发布说明

日期：2026-11-19。对应 Git Tag 为 `v1.1.4`。

## 修复的问题

1. **AGP 9 Built-in Kotlin + KSP 2.3.10+ 环形任务依赖**
   - 在 v1.1.3 中，`linRouter.hubMode=isolated` 通过 `variant.sources.kotlin?.addGeneratedSourceDirectory(...)` 将 `LinRouterAppHub.kt` 注册回 Kotlin 源码集，同时 `generate<Variant>LinRouterHub` 依赖 `ksp<Variant>Kotlin`。
   - 当接入方升级到 AGP 9（Built-in Kotlin）与 KSP 2.3.10+ 后，KSP 直接消费 `variant.sources.kotlin.all`，导致 `generate<Variant>LinRouterHub ↔ ksp<Variant>Kotlin` 形成循环依赖。
   - 本次改为在 `GenerateRouterHubTask` 中使用 ASM 直接生成 `com/lin/router/generated/LinRouterAppHub.class`，并通过 AGP 公开 API `variant.artifacts.forScope(ScopedArtifacts.Scope.PROJECT).use(hub).toAppend(ScopedArtifact.CLASSES, GenerateRouterHubTask::outputDirectory)` 注入类产物，彻底绕开源码集与主工程 `compileKotlin`。

2. **插件产物 JVM Target 一致性（JitPack JDK 17 与本地 JDK 21 对齐）**
   - 在 `linRouter/router-plugin/build.gradle.kts` 显式配置 `kotlin { jvmToolchain(17) }`、`JvmTarget.JVM_17` 与 `KotlinVersion.KOTLIN_2_0`，避免本地高版本 JDK 发布与 JitPack `openjdk17` 产出字节码版本不一致。

3. **冷启动期无效路由日志遍历**
   - 在 `LinRouter.init()` 与 `LinRouter.inject()` 中增加 `isLogEnabled(...)` 前置判断（同时保留自定义 `IRouterLogger` 行为），默认 `INFO` 级别下不再全量遍历 `routeMap` 拼接 `VERBOSE` 字符串。

## 变更范围

- **router-plugin**：移除 `kotlinpoet` 依赖，引入 `org.ow2.asm:asm:9.7.1`（仅构建期插件依赖，不打包进业务 APK，业务方无需接入 ASM）。`GenerateRouterHubTask` 保持 `@CacheableTask`，支持 Build Cache 与 Configuration Cache。
- **router-api**：优化 `LinRouter.kt` 日志前置过滤，无公共 API 变更。
- **router-compiler**：保持每模块最多 1 个 `RouterLoader` 与 1 个 `InterceptorLoader` 的极简结构，无行为变更。

## 兼容矩阵

| 组件 | `isolated` 模式支持范围 | 说明 |
| :--- | :--- | :--- |
| **Gradle** | 8.0 ~ 9.9.0 | 已在 Gradle 8.11.1 与 Gradle 9.9.0 实测通过；不支持 Gradle 7.x。 |
| **AGP** | 8.0 ~ 9.x | 已在 AGP 8.10.0 与 AGP 9（Built-in Kotlin）实测通过；未承诺 AGP 7.x 及以下。 |
| **KSP** | KSP2（2.1.x ~ 2.3.10+） | 依赖 KSP2 `KspAATask`；KSP1 请使用 `linRouter.hubMode=legacy`。 |
| **JDK** | JDK 17+ | 产物字节码为 Java 17（`major version: 61`），匹配 JitPack `openjdk17`。 |

## 升级与回退

升级 `linRoute` 至 `v1.1.4` 并在根 `gradle.properties` 中启用：

```properties
linRouter.hubMode=isolated
linRouter.aggregationMode=auto
```

如需回退旧行为，只需改为 `linRouter.hubMode=legacy`。

> 注：启用 `isolated` 后不再产出 `LinRouterAppHub.kt` 源码文件，生成的 `LinRouterAppHub.class` 位于对应变体的 AGP intermediates classes 目录，可通过 Android Studio 反编译或 `javap -c` 查看。

## 验证记录

- 插件单测与校验：`./gradlew :linRouter:router-plugin:test :linRouter:router-plugin:validatePlugins`（包含内存 `ClassLoader` 真实加载执行 ASM 字节码、TestKit `--configuration-cache` 与 `--build-cache` 回归）。
- 真实接入方验证：在 Gradle 9.9.0 + AGP 9 + KSP 2.3.10+ 多模块工程中启用 `linRouter.hubMode=isolated`，完成 `:erban_client:generateGoogleDebugLinRouterHub` 与 `:erban_client:dexBuilderGoogleDebug` 构建，并反编译确认 `LinRouterAppHub.class` 完整装载子模块与主工程 Loader/Interceptor。
